# Отчет по практическим занятиям 1-6

Дисциплина: **Фронтенд и бэкенд разработка**  
Тема проекта: **интернет-магазин компьютерной периферии**

В качестве итогового проекта я сделал небольшой интернет-магазин компьютерной периферии. В проекте есть фронтенд на React и бэкенд на Node.js + Express. Через сайт можно посмотреть список товаров, добавить новый товар, изменить уже существующий и удалить его.

## Структура проекта

- `backend` - серверная часть на Node.js и Express.
- `frontend` - клиентская часть на React.
- `frontend/src/App.js` - основной компонент магазина.
- `frontend/src/App.scss` - стили, написанные на SCSS.
- `frontend/src/api/index.js` - файл для запросов с фронтенда на бэкенд.
- `backend/app.js` - основной файл сервера, API и Swagger-документация.

## Практическое занятие 1

Тема: **CSS-препроцессоры SASS/LESS**

В первой практической нужно было сделать карточку товара и использовать CSS-препроцессор. Я выбрал **SASS/SCSS**, потому что он удобно подключается в React-проект.

В файле `frontend/src/App.scss` я использовал:

- переменные, например `$bg`, `$primary`, `$border`, `$text`;
- миксины `@mixin container` и `@mixin card`;
- вложенные селекторы, например `.product-card { &__title { ... } }`.

Карточка товара выводится на странице магазина. В ней есть фотография товара, название, категория, описание, цена и количество на складе.

## Практическое занятие 2

Тема: **Сервер на Node.js + Express**

Во второй практической нужно было реализовать API для списка товаров с CRUD-операциями. Для этого я сделал сервер в файле `backend/app.js`.

Реализованные маршруты:

- `GET /api/products` - получить список всех товаров;
- `GET /api/products/:id` - получить один товар по id;
- `POST /api/products` - добавить новый товар;
- `PATCH /api/products/:id` - изменить товар;
- `DELETE /api/products/:id` - удалить товар.

Объект товара содержит обязательные поля из задания:

- `id`;
- `name` - название товара;
- `price` - стоимость товара.

Также я добавил дополнительные поля, чтобы магазин выглядел полноценнее:

- `image`;
- `category`;
- `description`;
- `stock`;
- `rating`.

## Практическое занятие 3

Тема: **JSON, Postman и внешние API**

В этой практической нужно было проверить свое API через Postman и также выполнить запросы к внешнему API.

Для проверки моего API можно использовать такие запросы:

- `GET http://localhost:3000/api/products`;
- `GET http://localhost:3000/api/products/{id}`;
- `POST http://localhost:3000/api/products`;
- `PATCH http://localhost:3000/api/products/{id}`;
- `DELETE http://localhost:3000/api/products/{id}`.

Для `POST` и `PATCH` данные отправляются в формате JSON. Например:

```json
{
  "name": "Игровая мышь",
  "category": "Мышь",
  "description": "Проводная игровая мышь",
  "price": 2990,
  "stock": 10,
  "rating": 4.7
}
```

В качестве внешнего API можно использовать, например, API погоды или курсов валют. По заданию нужно выполнить не меньше 5 запросов и добавить скриншоты результатов в репозиторий.

## Практическое занятие 4

Тема: **Связь API и React-приложения**

В четвертой практической нужно было сделать два приложения, которые работают вместе: сервер Express и клиент React. Я сделал сайт интернет-магазина компьютерной периферии.

На фронтенде реализовано:

- загрузка товаров с сервера;
- вывод карточек товаров;
- форма добавления нового товара;
- редактирование товара;
- удаление товара;
- модальное окно для создания и изменения товара.

Запросы к серверу находятся в файле `frontend/src/api/index.js`. Для запросов используется библиотека `axios`.

В проекте есть 10 товаров. У каждого товара есть название, категория, описание, цена и количество на складе. Также добавлены фотографии товаров.

## Практическое занятие 5

Тема: **Swagger-документация**

В пятой практической нужно было подключить Swagger и описать CRUD-операции. Я подключил библиотеки:

- `swagger-jsdoc`;
- `swagger-ui-express`.

Документация описана прямо в `backend/app.js` через JSDoc-комментарии. Для API описана схема `Product` и все основные маршруты.

Swagger открывается по адресу:

```text
http://localhost:3000/api-docs
```

Через Swagger можно посмотреть описание API и сразу выполнить тестовые запросы.

## Практическое занятие 6

Тема: **Подготовка к контрольной работе N1**

Шестая практическая является итоговой. В ней нужно было собрать все предыдущие задания в один проект и подготовить его к сдаче.

В итоге в проекте есть:

- фронтенд на React;
- бэкенд на Express;
- CRUD API для товаров;
- карточки товаров со стилями на SCSS;
- связь фронтенда с бэкендом через axios;
- Swagger-документация;
- README-отчет по практическим занятиям.

Проект можно загрузить в открытый репозиторий и прикрепить ссылку в СДО.

## Как запустить проект

Сначала нужно запустить бэкенд:

```bash
cd backend
npm start
```

После запуска будут доступны:

- API: `http://localhost:3000/api/products`;
- Swagger: `http://localhost:3000/api-docs`.

Потом нужно запустить фронтенд в отдельном терминале:

```bash
cd frontend
npm run dev
```

Так как бэкенд работает на порту `3000`, фронтенд лучше запускать на порту `3001`. Именно этот адрес разрешен в настройках CORS на сервере.
